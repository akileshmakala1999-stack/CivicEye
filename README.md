## How to Make Changes and Contribute

Because this is a public repository, anyone can inspect, clone, modify, and contribute to CivicEye.

### Method 1: Edit Online in the Browser (No Installation)
1. In this repository, press the `.` (period) key on your keyboard to open GitHub's web editor.
2. Or open with GitHub Codespaces by clicking **Code** > **Codespaces** > **Create codespace on main**.
3. Make your edits and commit them.

### Method 2: Run and Edit Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/akileshmakala1999-stack/CivicEye.git
   cd CivicEye
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

### Method 3: Fork and Submit a Pull Request
1. Click **Fork** at the top right of this page.
2. Create your feature branch (`git checkout -b feature/my-update`).
3. Commit and push your changes.
4. Click **New Pull Request** to submit your improvements.

## Adding Direct Collaborators
To give specific people direct push permissions:
1. Open **Settings** > **Collaborators** on this repository.
2. Click **Add people** and enter their GitHub username.
3. Once accepted, they can push commits directly to `main`.
